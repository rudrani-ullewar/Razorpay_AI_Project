Razorpay AI Project

An AI-powered transaction analysis project that analyzes transaction data and presents meaningful insights through an interactive dashboard.

Features

* Transaction data analysis
* Interactive dashboard
* Data visualization
* Transaction search and filtering
* AI-based transaction insights

Technologies Used

* Python
* Pandas
* Streamlit
* Data Analysis
* CSV

Project Structure

* app.py – Main application
* transactions.csv – Transaction dataset
* requirements.txt – Required Python libraries

 How to Run

Install the required dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

Purpose

This project helps businesses analyze failed transactions, understand revenue at risk, identify important recovery opportunities, and make data-driven decisions to improve payment recovery.

Future Improvements

* Machine learning-based recovery prediction
* Real-time payment monitoring
* Automated customer notifications
